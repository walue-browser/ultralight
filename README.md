# Ultralight Samples

This repository contains sample applications demonstrating how to use the Ultralight SDK, a lightweight, high-performance HTML renderer for game and app developers.

## Samples Included

1. **Sample 1 - Render to PNG**: Demonstrates how to render HTML to a PNG image.
2. **Sample 2 - Basic App**: Shows how to create a basic application with Ultralight.
3. **Sample 3 - Resizable App**: Demonstrates a resizable application window.
4. **Sample 4 - JavaScript**: Shows JavaScript integration with Ultralight.
5. **Sample 5 - File Loading**: Demonstrates loading local files.
6. **Sample 6 - Intro to C API**: Introduction to the C API.
7. **Sample 7 - OpenGL Integration**: Shows how to integrate Ultralight with OpenGL.
8. **Sample 8 - Web Browser**: A simple web browser implementation.
9. **Sample 9 - Multi Window**: Demonstrates multiple window support.
10. **FPS Test**: Performance testing sample for HTML rendering.

## Building the Samples

To build the samples, you need to:

1. Download the Ultralight SDK from [https://ultralig.ht/download](https://ultralig.ht/download)
2. Extract the SDK to the `SDK` directory in the root of this repository
3. Create a build directory: `mkdir build && cd build`
4. Configure with CMake: `cmake ..`
5. Build: `make`
