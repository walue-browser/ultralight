# Ultralight FPS Test Release

This release contains the compiled FPS test application for Ultralight, which measures HTML rendering performance using C++ generated content.

## Contents

- `fpstest/` - Directory containing the FPS test application and its dependencies

## Requirements

- Linux x64 system
- X11 display server

## Running the Application

```bash
cd fpstest
./fpstest
```

## Performance Results

In our testing environment, the application achieved approximately 62 FPS rendering complex HTML content.

## Building from Source

To build the application from source:

1. Download the Ultralight SDK from the official website
2. Clone the repository: `git clone https://github.com/walue-browser/ultralight.git`
3. Follow the build instructions in the repository
